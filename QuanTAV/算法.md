# Python QuanTAV 瘤周血管算法说明

本文档说明 `python/quantav_py` 中的瘤周血管分析流程。它对应 MATLAB 版 QuanTAV 核心思想，但做了 Python 化封装：输入 CT 图像可选，核心输入是肿瘤 `tumor_mask` 和血管 `vessel_mask`，输出 91 维特征、分支级 CSV 和多种可视化图。

相关代码入口：

- `quantav_py.api.analyze_case()`：完整流程入口。
- `quantav_py.roi.prepare_roi()`：清理肿瘤 mask，生成瘤周 ROI，并提取瘤周血管。
- `quantav_py.skeleton.skeletonize_and_extract_branches()`：三维中心线骨架提取和分支拆分。
- `quantav_py.features.compute_quantav_features()`：91 维 QuanTAV 风格特征计算。
- `quantav_py.visualization.create_visualizations()`：3D、切片、MIP、中心线、投影图和统计图输出。

## 1. 输入和坐标约定

### 1.1 输入

`analyze_case()` 支持 NumPy 数组或文件路径：

```python
from quantav_py import QuantavParams, analyze_case

params = QuantavParams(
    spacing=(1.0, 1.0, 1.0),
    peritumoral_radius_mm=30.0,
    min_vessel_component_size=20,
    create_visualizations=True,
)

result = analyze_case(
    image=None,
    tumor_mask="tumor.nii.gz",
    vessel_mask="vessel.nii.gz",
    params=params,
    output_dir="./output",
    case_id="case001",
)
```

参数含义：

- `image`：CT 体数据。当前特征计算不依赖 CT 灰度，主要用于可视化背景。
- `tumor_mask`：三维肿瘤二值 mask，非零表示肿瘤。
- `vessel_mask`：三维血管二值 mask，非零表示血管。
- `spacing`：数组轴顺序下的体素间距，单位 mm。
- `target_spacing`：可选重采样目标间距。若设置，会把 image、tumor、vessel 重采样到同一 spacing。
- `peritumoral_radius_mm`：瘤周区域半径，单位 mm。

### 1.2 轴顺序

Python 版统一使用 NumPy 体数据常见顺序：

```text
array.shape = (z, y, x)
spacing     = (z_mm, y_mm, x_mm)
```

`load_volume()` 使用 SimpleITK 读取 NIfTI、NRRD、MHA 等文件时，SimpleITK 原始 spacing 是 `(x, y, z)`，函数会自动反转成 `(z, y, x)`，保证 spacing 和 NumPy 数组轴顺序一致。

### 1.3 文件读取

读取逻辑：

1. `.npy`：直接用 `numpy.load()`。
2. 医学图像：优先用 SimpleITK。
3. SimpleITK 失败后，尝试 nibabel。

建议对 NIfTI、NRRD 数据优先依赖 SimpleITK，因为它能更一致地处理 spacing、origin、direction 等医学图像元信息。

## 2. 总体流程

完整流程如下：

```text
输入 image / tumor_mask / vessel_mask
        |
        v
读取体数据和 spacing
        |
        v
可选重采样到 target_spacing
        |
        v
清理 tumor_mask：最大连通域、填洞
        |
        v
计算肿瘤外距离图，生成瘤周 ROI
        |
        v
vessel_mask 与瘤周 ROI 相交，并排除肿瘤内部
        |
        v
删除过小血管连通域
        |
        v
按 tumor + peritumoral vessel 裁剪 ROI
        |
        v
对 vessel | tumor 做 3D 骨架化
        |
        v
把骨架拆成分支 centerline
        |
        v
计算 61 个 morphology 特征
        |
        v
计算 30 个 organization 特征
        |
        v
保存 CSV 和可视化图
```

核心结果：

- `result.features`：长度为 91 的特征向量。
- `result.feature_names`：91 个特征名。
- `result.morphology`：前 61 个形态特征。
- `result.organization`：后 30 个空间组织特征。
- `result.branches`：经过过滤后真正参与形态学分析的中心线分支。
- `result.metadata`：病例 ID、spacing、体素数、体积、中心线长度、分支数等辅助信息。

## 3. 瘤周 ROI 和瘤周血管提取

文件：`quantav_py/roi.py`

### 3.1 肿瘤 mask 清理

肿瘤 mask 先转成布尔数组：

```python
tumor = tumor_mask > 0
```

如果 `params.clean_tumor=True`，只保留最大三维连通域。这样可以去除零散误标注。

如果 `params.fill_tumor_holes=True`，对肿瘤 mask 做三维填洞，让肿瘤区域更完整。

### 3.2 肿瘤外距离图

用欧氏距离变换计算每个肿瘤外体素到肿瘤边界的距离：

```python
distance_to_tumor = distance_transform_edt(~tumor, sampling=spacing)
```

`sampling=spacing` 很重要。它让距离以 mm 为单位，而不是简单按体素数计算。对于非等距体素，例如 `(1.5, 0.75, 0.75)`，这一步能避免 z 方向距离被低估或高估。

### 3.3 瘤周区域

瘤周 ROI 定义为距离肿瘤不超过 `peritumoral_radius_mm` 的区域：

```python
peritumoral = distance_to_tumor <= peritumoral_radius_mm
```

注意：肿瘤内部距离为 0，所以也会包含在 `peritumoral` 中。后续提取血管时会排除肿瘤内部。

### 3.4 瘤周血管

瘤周血管由原始血管 mask、瘤周 ROI 和肿瘤外区域共同决定：

```python
vessel = vessel_mask & peritumoral & ~tumor
```

含义：

- 保留已经分割出的血管。
- 只保留肿瘤附近一定半径内的血管。
- 删除肿瘤内部体素，避免把肿瘤误当成血管。

之后删除小连通域：

```python
vessel = remove_small_components(vessel, min_vessel_component_size)
```

`min_vessel_component_size` 越大，噪声越少，但细小真实血管也可能被删除。

### 3.5 ROI 裁剪

如果 `params.crop_to_roi=True`，会围绕 `tumor | peritumoral | vessel` 的包围盒裁剪体数据。这样能减少骨架化和可视化计算量，也能让输出图聚焦在肿瘤附近。

`crop_margin_mm` 控制裁剪边界额外保留多少 mm。

## 4. 三维中心线骨架提取

文件：`quantav_py/skeleton.py`

### 4.1 为什么要提取中心线

血管 mask 是三维体素块，包含血管粗细、分割厚度和局部噪声。如果直接在体素块上计算弯曲程度，会受到血管直径和阈值影响。QuanTAV 的核心思想是把血管压缩成一像素宽的中心线，再在中心线上分析：

- 血管分支长度。
- 分支端点之间的直线距离。
- 血管弯曲程度。
- 局部曲率。
- 血管走向的空间组织模式。

中心线可以理解为血管的“骨干路径”。

### 4.2 骨架化对象

默认设置：

```python
skeleton_input = vessel | tumor
```

即对瘤周血管和肿瘤区域的并集做骨架化。这样做与 MATLAB QuanTAV 的习惯一致：

```matlab
S = skeleton(seg_v | seg_t)
```

这样可以识别哪些血管分支接近或进入肿瘤。随后计算血管形态时会删除肿瘤内部点，只保留肿瘤外血管段。

如果希望只对血管本身骨架化，可以设置：

```python
QuantavParams(skeletonize_tumor_union=False)
```

但这会影响 feeding vessel 的判定，通常不建议作为默认。

### 4.3 3D skeletonize

Python 使用：

```python
skimage.morphology.skeletonize(mask)
```

输入三维布尔体，输出一体素宽的三维骨架。

骨架体素满足：

- 仍然保持原始结构的连通关系。
- 血管粗细被压缩掉。
- 适合转成图结构并拆分成分支。

### 4.4 骨架转图

骨架中的每个非零体素视为一个节点。三维 26 邻域中相邻的骨架体素视为边。

对每个节点统计邻居数量，也就是图的 degree：

- `degree = 1`：端点。
- `degree = 2`：普通路径点。
- `degree > 2`：分叉点。
- `degree = 0`：孤立点。

端点和分叉点统称 critical node。分支拆分规则：

1. 从每个 critical node 出发。
2. 沿 degree 为 2 的路径一直走。
3. 遇到另一个 critical node 时停止。
4. 这一段路径就是一个 branch。

如果遇到完全闭合环路，所有点 degree 都等于 2，没有端点和分叉点，代码会额外把它作为 cycle branch 输出。

### 4.5 分支过滤

不是所有骨架分支都参与形态计算。每个分支会经过以下处理：

1. 四舍五入成整数体素坐标。
2. 裁剪到图像边界内。
3. 标记是否有点进入肿瘤。
4. 删除肿瘤内部点。
5. 删除相邻重复点，避免曲率爆炸。
6. 如果分支点数少于 `min_branch_points`，跳过。
7. 如果曲率点太少或曲率全相同，跳过。

默认 `min_branch_points=11`，对应 MATLAB 中“只分析长度超过 10 个点的分支”的规则。

## 5. 形态特征 Morphology，61 维

文件：`quantav_py/features.py`

形态特征描述的是“血管本身长什么样”。它关注单条血管分支和整个血管网络的几何形状，例如弯不弯、曲率高不高、血管量多不多、是否有 feeding vessel。

### 5.1 分支长度和弦长

对一个中心线分支，设点序列为：

```text
p1, p2, p3, ..., pn
```

每个点先乘以 spacing，转成 mm 坐标：

```text
p_mm = p_vox * spacing
```

分支中心线长度：

```text
length = sum(||p(i+1) - p(i)||)
```

分支端点弦长：

```text
chord = ||pn - p1||
```

### 5.2 扭曲度 / tortuosity

代码中沿用 MATLAB 变量名 `torsion`，但它更准确地说是血管 tortuosity 或弯曲迂曲程度：

```text
torsion = 1 - chord / length
```

解释：

- 如果血管几乎是直线，`chord` 接近 `length`，torsion 接近 0。
- 如果血管很弯，`length` 明显大于 `chord`，torsion 增大。
- 这个值是无量纲的。

### 5.3 局部曲率

对每三个相邻中心线点 `p1, p2, p3`，拟合它们所在圆的半径 `R`，曲率为：

```text
curvature = 1 / R
```

Python 中用三点外接圆等价公式：

```text
curvature = 2 * ||(p2 - p1) x (p3 - p1)|| /
            (||p2 - p1|| * ||p3 - p2|| * ||p3 - p1||)
```

单位是 `1/mm`。曲率越大，局部弯折越强。

### 5.4 分支级曲率统计

每条有效分支都会得到一串局部曲率值。对这些曲率计算：

- `mean_curvature`：平均曲率。
- `std_curvature`：曲率波动程度。
- `max_curvature`：最强局部弯折。
- `skewness`：曲率分布偏态。
- `kurtosis`：曲率分布峰态。

### 5.5 feeding vessel

如果一条原始骨架分支在删除肿瘤内部点之前曾经过肿瘤区域，则视为进入或连接肿瘤的 feeding vessel。

输出：

- feeding vessel 数量。
- feeding vessel 在有效分支中的比例。

这类特征可理解为“有多少血管直接指向或进入肿瘤”。

### 5.6 61 维特征组成

前 35 维：7 组统计，每组 5 个统计量：

每组统计量顺序：

```text
mean, std, max, skewness, kurtosis
```

7 组对象：

1. 分支 torsion。
2. 每条分支平均曲率。
3. 每条分支曲率标准差。
4. 每条分支最大曲率。
5. 每条分支曲率偏态。
6. 每条分支曲率峰态。
7. 全部中心线点的局部曲率。

中间 20 维：

- 全部中心线点曲率 10-bin 直方图。
- 分支 torsion 10-bin 直方图。

最后 6 维：

1. `morph_vessel_volume_voxels`：瘤周血管体素数。
2. `morph_vessel_density`：血管体素数 / ROI 体素数。
3. `morph_vessel_to_tumor_volume_ratio`：血管体素数 / 肿瘤体素数。
4. `morph_skeleton_points_total`：有效中心线分支点数总和。
5. `morph_feeding_vessel_count`：feeding vessel 数量。
6. `morph_feeding_vessel_fraction`：feeding vessel 比例。

合计：

```text
7 * 5 + 10 + 10 + 6 = 61
```

### 5.7 这些形态特征表示什么

可以按临床或影像学含义粗略理解为：

- 血管量：血管体素数、血管密度、血管和肿瘤体积比。
- 血管弯曲：torsion、曲率均值、最大曲率。
- 血管复杂度：曲率标准差、曲率直方图、torsion 直方图。
- 血管连接肿瘤程度：feeding vessel 数量和比例。

这些值不是直接诊断指标，而是供后续统计建模、分类、回归或生存分析使用的定量影像特征。

## 6. 空间组织特征 Organization，30 维

文件：`quantav_py/features.py`

空间组织特征描述的是“血管围绕肿瘤怎么排列”。它不只看单条血管弯不弯，而是看整个瘤周血管网络的方向分布、放射状程度、局部走向一致性等。

### 6.1 为什么需要投影

三维血管方向很复杂。QuanTAV 把三维血管投影成 6 张二维图，然后在二维图中用 Hough 变换统计局部方向。

6 张投影分两类：

1. 笛卡尔投影，来自血管体素。
2. 球坐标投影，来自中心线点。

每张投影图输出 5 个方向统计量：

```text
mean, median, std, skewness, kurtosis
```

因此：

```text
6 张投影 * 5 个统计量 = 30 维 organization 特征
```

### 6.2 距离范围过滤

organization 默认只分析距离肿瘤表面一定范围内的血管：

```python
organization_distance_range_mm = (0.0, 11.0)
```

也就是只保留肿瘤外 0 到 11 mm 范围内的血管点。

这个设置和原 MATLAB QuanTAV 默认值一致。对于肺 CT，如果你希望更局部，可以改成 `(0.0, 7.0)`；如果希望覆盖更宽瘤周区域，可以增大上限。

### 6.3 三张笛卡尔投影

先把距离范围内的瘤周血管体素取出来，得到 `projected_volume`。

然后沿三个方向最大投影：

```text
axis0-axis1 投影：沿 axis2 压缩
axis0-axis2 投影：沿 axis1 压缩
axis1-axis2 投影：沿 axis0 压缩
```

对应直观含义：

- 从三个正交方向看血管网络的二维投影。
- 观察局部血管线条在二维平面内的方向。

### 6.4 三张球坐标投影

球坐标投影使用中心线点，而不是体素块。原因是中心线更能代表血管走向。

步骤：

1. 计算肿瘤质心。
2. 把中心线点坐标转成相对肿瘤质心的坐标。
3. 计算每个中心线点：
   - `rotation/theta`：水平旋转角。
   - `elevation/phi`：仰角。
   - `distance/r`：到肿瘤表面的距离。
4. 生成三张二维图：
   - elevation-rotation。
   - distance-rotation。
   - distance-elevation。

球坐标投影的意义：

- `elevation-rotation`：血管覆盖了肿瘤周围哪些角度区域。
- `distance-rotation`：不同方向上的血管离肿瘤有多远。
- `distance-elevation`：不同高度方向上的血管距离分布。

### 6.5 中心线插值

中心线相邻点之间可能比较稀疏，投影到球坐标图后可能出现断裂。因此代码会在相邻中心线点之间插入若干点：

```python
spherical_interpolation_points = 50
```

插值只用于球坐标投影和 organization 特征，不改变原始血管 mask。

### 6.6 Hough 方向统计

每张二维投影图会被滑动窗口扫描：

```python
organization_window_size = 35
organization_window_step = round(window_size / 3)
```

对每个非空窗口：

1. 使用 `skimage.transform.hough_line()` 做 Hough 线检测。
2. 使用 `hough_line_peaks()` 取前几个方向峰。
3. 把这些方向角收集起来。

最后对所有窗口的方向角计算：

```text
mean, median, std, skewness, kurtosis
```

这些统计量表示：

- `mean/median`：整体方向偏向。
- `std`：方向离散程度，越大说明走向越杂乱。
- `skewness`：方向分布是否偏向某一侧。
- `kurtosis`：方向是否集中在少数强方向上。

### 6.7 30 维特征组成

特征顺序：

1. `org_cartesian_axis0_axis1_*`
2. `org_cartesian_axis0_axis2_*`
3. `org_cartesian_axis1_axis2_*`
4. `org_spherical_elevation_rotation_*`
5. `org_spherical_distance_rotation_*`
6. `org_spherical_distance_elevation_*`

每个 `*` 包含：

```text
mean, median, std, skewness, kurtosis
```

合计：

```text
6 * 5 = 30
```

### 6.8 这些空间组织特征表示什么

可以按以下方向理解：

- 血管方向是否一致：方向标准差低，表示局部血管走向更一致。
- 血管是否呈放射状或环绕状：球坐标投影能体现血管相对肿瘤的角度分布。
- 血管是否只集中在某些方位：方向偏态和峰态能反映方向分布不均衡。
- 血管是否贴近肿瘤表面：distance 相关投影关注距离维度。

形态特征回答“血管本身有多弯、多复杂、多密”，组织特征回答“这些血管在肿瘤周围如何排列”。

## 7. 可视化输出

文件：`quantav_py/visualization.py`

如果 `create_visualizations=True` 且传入 `output_dir`，会输出多种图像和一个分支 CSV。

### 7.1 `case_tumor_vessels.png`

三维表面图：

- 青色：肿瘤。
- 红色：瘤周血管体素。
- 白色：参与分析的中心线分支。

用途：

- 快速检查血管是否真的围绕肿瘤。
- 检查 ROI 是否过大或过小。
- 检查中心线是否贴合血管。

### 7.2 `case_skeleton_branches.png`

三维中心线分支图：

- 半透明青色：肿瘤。
- 彩色线：中心线分支，颜色按分支长度映射。
- 黄色粗线：feeding vessel。

用途：

- 检查骨架是否断裂。
- 检查分支拆分是否合理。
- 检查 feeding vessel 判定是否可信。

### 7.3 `case_central_slices.png`

三个过肿瘤中心的正交切片：

- axial。
- coronal。
- sagittal。

叠加层：

- 黄色：瘤周 ROI。
- 青色：肿瘤。
- 红色：血管。
- 白色：骨架。

用途：

- 最适合做病例级 QA。

### 7.4 `case_mip_overview.png`

三个方向的最大密度投影：

- XY MIP。
- XZ MIP。
- YZ MIP。

叠加层同上。

用途：

- 比单切片更容易看完整血管网络。

### 7.5 `case_curvature.png`

三维中心线曲率图：

- 肿瘤半透明显示。

- 颜色条单位是 `1/mm`。

用途：

- 查看哪些血管段局部弯曲强。
- 检查异常高曲率是否来自噪声、断裂或中心线抖动。

### 7.6 `case_torsion.png`

三维分支 torsion 图：

- 每条分支使用一个颜色。
- 颜色表示该分支整体迂曲程度。

用途：

- 查看哪些分支整体更弯曲。
- 和曲率图配合使用：曲率看局部，torsion 看整条分支。

### 7.7 `case_feature_distributions.png`

- 分支长度直方图。
- 平均曲率直方图。
- 最大曲率直方图。

用途：

- 检查特征是否被少数异常分支主导。

## 8. 输出 CSV 和 metadata

### 8.1 91 维特征 CSV

`save_features_csv()` 会输出：

```text
case_id, feature_1, feature_2, ..., feature_91
```

第一列是病例 ID，后面 91 列是特征。

### 8.2 metadata

`result.metadata` 包含：

- `n_raw_branches`：原始骨架分支数量。
- `n_analyzed_branches`：最终参与形态计算的分支数量。
- `vessel_voxels`：ROI 中血管体素数。
- `peritumoral_vessel_voxels`：排除肿瘤内部后的瘤周血管体素数。
- `vessel_volume_mm3`：血管体积，单位 mm3。
- `tumor_voxels`：肿瘤体素数。
- `tumor_volume_mm3`：肿瘤体积，单位 mm3。
- `skeleton_voxels`：骨架体素数。
- `analyzed_skeleton_length_mm`：参与分析的中心线分支长度总和。
- `feeding_vessel_count`：feeding vessel 数量。
- `crop_slices`：裁剪范围。
- `spacing`：最终用于计算的 spacing。
- `visualization_paths`：所有图像输出路径。

这些 metadata 不进入 91 维主特征，以保持和 MATLAB 风格输出兼容，但很适合做质量控制。

## 9. Python 版和 MATLAB 版的主要差异

### 9.1 骨架化方法不同

MATLAB 原始 QuanTAV 使用 Fast Marching 相关 skeleton 方法。Python 版使用 `skimage.morphology.skeletonize` 加图分支拆分。

因此：

- 特征定义保持一致。
- 输出维度和大类顺序保持一致。
- 数值不会和 MATLAB 逐位完全相同。

这是预期行为。Python 版更方便部署和批处理，MATLAB 版更接近原始研究代码。

### 9.2 spacing 处理更显式

Python 版所有长度、距离、曲率和体积 metadata 都基于 `spacing`。如果输入是非等距体素，必须保证 spacing 正确。

### 9.3 可视化更多

MATLAB 版主要输出 3D 肿瘤血管图、曲率图、torsion 图。Python 版新增了：

- 中心切片叠加。
- 三方向 MIP。
- 分支长度和 feeding vessel 图。
- 组织投影图。
- 分支级 CSV。

这些图更适合检查每一步是否可靠。

## 10. 参数建议

### 10.1 常用默认值

```python
QuantavParams(
    spacing=(1.0, 1.0, 1.0),
    target_spacing=None,
    peritumoral_radius_mm=30.0,
    min_vessel_component_size=20,
    min_branch_points=11,
    organization_distance_range_mm=(0.0, 11.0),
    organization_window_size=35,
    spherical_projection_size=400,
    spherical_interpolation_points=50,
)
```

### 10.2 肺 CT 建议

如果数据已经重采样到 1 mm：

```python
spacing=(1.0, 1.0, 1.0)
```

如果希望更贴近肿瘤表面：

```python
organization_distance_range_mm=(0.0, 7.0)
```

如果血管分割有较多小噪声：

```python
min_vessel_component_size=30
```

如果中心线断裂较多，先检查血管分割，不建议单纯降低 `min_branch_points`。降低后会引入大量短分支，可能放大噪声。

### 10.3 非等距体素

如果原始 spacing 是 `(z=1.5, y=0.75, x=0.75)`，应传：

```python
spacing=(1.5, 0.75, 0.75)
```

也可以重采样到统一 spacing：

```python
QuantavParams(
    target_spacing=(1.0, 1.0, 1.0)
)
```

## 11. 质量控制建议

每个病例至少检查：

1. `central_slices`：肿瘤、血管、骨架是否对齐。
2. `mip_overview`：血管是否只在瘤周范围内，是否有明显外部噪声。
3. `tumor_vessels`：3D 结构是否符合预期。
4. `skeleton_branches`：中心线是否断裂过多，feeding vessel 是否合理。
5. `feature_distributions`：是否有极端异常分支。
6. `organization_projections`：投影是否为空或过于稀疏。

如果某个病例输出：

- `n_analyzed_branches = 0`：通常说明血管 mask 太少、中心线太短、或 `min_branch_points` 太高。
- `vessel_volume_mm3 = 0`：说明瘤周 ROI 内没有血管，或输入血管 mask 与肿瘤不在同一空间。
- organization 特征大量为 0：可能是投影图为空，或血管距离不在 `organization_distance_range_mm` 内。

## 13. 一句话总结

这套 Python QuanTAV 流程做的是：先从肿瘤 mask 周围提取一定物理半径内的血管，再把血管和肿瘤并集骨架化成中心线分支，随后用 61 个形态特征描述血管“有多少、弯不弯、复杂不复杂、是否进入肿瘤”，用 30 个空间组织特征描述血管“在肿瘤周围朝哪个方向、是否集中、是否有规律地分布”，最后通过多种 2D/3D 图像检查每一步是否可信。
